# Xuyuan Xiong - Personal Homepage

Static academic homepage for `xjxyys.github.io`, organized around the reference
layout provided by the site owner.

## Content

- Biography and contact links
- News
- Industry experience (the research experience section is kept commented out in `index.html`)
- Education
- Selected publications and projects
- Blog: one card per post, linking to the post under `blog/`
- Awards and technical skills

## Preview

Open `index.html` directly in a browser. The site is plain HTML and CSS and can
be published from the repository root with GitHub Pages.

## Main files

- `index.html` - page content
- `styles.css` - layout and colors
- `assets/institutions/` - locally stored institution marks
- `assets/papers/` - publication teaser and representative figures
- `blog/<post>/` - each blog post as a self-contained rendered page; the homepage card uses the post's own cover
  image (`blog/looping-twice/` is rendered from `blog/param-savings/` of `xjxyys/loop-scaling-fb`)
- `truncate-or-not/` - the project page of the Truncate or Not? paper

## Institution assets

- HKU crest: HKU Department of Civil Engineering website
- SJTU mark: Shanghai Jiao Tong University Visual Identity System
- Yale wordmark: Yale University website

Publication images are sourced from the corresponding author/project pages or
the publicly available paper PDF. The SPOT image is Figure 2 from the paper.
